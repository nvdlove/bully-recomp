Re-skinning: Export saves every texture the game has loaded so far as a PNG in bullygfx_textures\export, named after the game's file (e.g. zrc_asphalt_swap_d is the bus yard tarmac; _d colour, _n normal map, _s shine). Edit a copy, save it under the same name in bullygfx_textures\replace, pick Replaced and press Reload. Any size works. Walk around first so the textures you want are loaded.

Mods

Mods load straight from their own folders: nothing gets copied into the game. Switch them on and off while you play and the buildings and textures swap on the spot.

How it works

Pick the folder the mod came in: the one with its World.img and World.dir (or a Stream folder with them), and its texture folders. Only what the mod changes is used, so several mods can be on at once; when two change the same thing, the lower one in the list wins (▲ moves one up).

Textures are read as PNG when there is a PNG copy with the same name (edit those in anything), otherwise from the mod's own files. The first time, PNGs are packed for the game once and cached, so a new mod can stutter for a moment while that happens.

Switching live: buildings, props and texture packs change right away. People and cars keep their look until they respawn, and a few kinds of files only change after a restart (the count shows above).
